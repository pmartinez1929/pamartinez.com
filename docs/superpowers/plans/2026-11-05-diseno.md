# Mejoras de diseño visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar el rediseño aprobado:
- títulos de sección con etiqueta y título grande;
- botones del hero del mismo ancho, con "Ver proyectos" en navy;
- "Cómo trabajo" con intro y lista;
- proyectos como tarjetas con datos visibles;
- Intuyo como banda navy sin foto de fondo.

**Architecture:** Sitio Astro estático sin JS en el cliente.
- Un componente nuevo, `SectionHeading.astro`, reemplaza las pastillas `.pill` en todas las secciones.
- Los textos de los títulos viven en `site.sections` (`src/data/site.ts`).
- Cada tarea rediseña una sección y elimina los campos de datos que deja sin uso.
- Los tests (`node:test` + `node-html-parser`) inspeccionan `dist/index.html` después de `astro build`.

**Tech Stack:** Astro 7.4.5, Tailwind CSS 4.3.4, TypeScript, `node:test`, `node-html-parser`.

**Spec:** `docs/superpowers/specs/2026-11-05-diseno-design.md`

## Global Constraints

- Cero JavaScript en el cliente: nada de `<script>`.
- Todo link externo lleva `target="_blank" rel="noopener noreferrer"`, verificado con `isSafeExternal`.
- Textos en español exactamente como en el plan, con tildes y flechas `→`.
- `tests/links.test.mjs` no se modifica: todos sus destinos deben seguir presentes.
- Archivos con fin de línea LF. Para editar tests con regex usa la herramienta Edit, no `sed`/heredocs: antes, `\b` terminó convertido en backspace.
- Tests completos: `npm test`.
- Un archivo: `npm run build && node --test tests/<archivo>.test.mjs`.
- Type-check: `npm run check` → 0 errors.
- El commit termina con un trailer `Co-Authored-By:` que nombra el modelo que lo escribió.
- No hacer `git push`.
- Colores Tailwind:
  - `navy` #1d3557
  - `blue` #457b9d
  - `aqua` #a8dadc
  - `cream` #f1faee
  - `red` #e63946
  - `ink`
  - `muted`
- Fuentes: `font-display` (Vidaloka, solo 400) y `font-sans` (Quicksand).
- El orden de secciones y sus `id` no cambian: inicio, clientes, servicios, proceso, proyectos, intuyo, sobre-mi, contacto.
- `a:focus-visible` global dibuja un outline navy. Sobre fondo navy hay que agregar `focus-visible:outline-white`.
